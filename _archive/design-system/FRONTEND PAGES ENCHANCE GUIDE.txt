  Page-by-page punch list

  Dashboard

  - Page header is plain. Add a mono-caps eyebrow ("Admin · Live") above the title, and apply the brand-gradient
  wordmark to the title itself.
  - Recharts is monochrome. Use <linearGradient> defs in <defs> for bar fills and pie segments. Tooltip background
  should be frosted glass with a hairline gradient border.
  - BentoCards have a top stripe but nothing else. Add a hover-following radial mouse glow (already wired via --mx/--my
  in index.css — just apply the listener).
  - No "live" feel. Pulse a tiny dot next to "Active Tasks" when count > 0 (.pulse-dot is already defined; not used
  here).
  - Activity feed is dense gray text. Each row should have a left accent-color stripe matching the action type.

  Upload

  - Dropzone is a static dashed box. Add an animated gradient border (conic-gradient rotation) when the drop zone is
  "active" — it's the most-touched element on the page and currently feels dead.
  - Empty state is just the dropzone. Add a 3-step illustrated guide ("1. Drop files → 2. We split scenes → 3. Review")
  below it.
  - File queue is a flat list. Cards should slide in with a stagger on add, slide out when removed. Currently +1 file is
   invisible until you scroll.
  - Progress bars are plain blue rectangles. Use the brand gradient and add a subtle traveling shimmer on bars that are
  actively processing.

  OrganizedVideos

  - Folder cards are flat. Each folder should have its own accent color (you already have labelColors) — apply that as a
   top stripe + faint radial glow tinted to the folder's color, not just on the badge.
  - Metadata strip at 0.04 opacity is invisible. Bump to a proper card with a hairline gradient border. Right now it
  reads as a footnote.
  - Pagination buttons are plain text. Use the same pill btn-ghost style from landing nav.
  - Filter controls aren't using the new .chip class I added to index.css. The CSS exists; nothing references it.
  Convert label filters to chips.
  - Logs panel is a wall of gray. Row hover should highlight with the row's status color, not just lift.

  Settings

  - Tabs sidebar is invisible. Active tab needs a left accent bar (4px brand gradient) — currently only background
  changes.
  - Forms are flatlined. Inputs need an animated focus ring (the --focus-ring token exists; the animation doesn't). On
  focus, the label should color-shift to accent.
  - Danger zone is the only colored section. That's correct — but it needs a soft red ambient glow, not just a border.
  - Avatar/profile section has no visual interest. Add a gradient ring around the user avatar matching the brand
  gradient.
  - No save-feedback. Add a brief success toast with a checkmark animation when settings save.

  JobMonitor

  - Data table is a wall of gray rows. Row left border should be 3px wide and colored by status (running=accent,
  failed=danger, completed=success). One change, huge impact.
  - No skeleton on first load. Currently shows nothing or a generic spinner. Add 5–8 skeleton rows.
  - Status badges don't pulse. "Running" should pulse softly. "Failed" should have a red glow.
  - Header counters ("5 Running, 2 Failed") are inline plain text. Promote to chip-style stat pills with their semantic
  color.
  - Modals are flat overlays. Backdrop should be blurred, modal should slide+fade in (200ms cinematic ease, not
  instant).

  Inspector (Moderation Queue)

  - Filter sidebar uses regular buttons. Should use .chip and the .filter-bar styles I added.
  - Clip cards lift on hover but the shadow is plain gray. Tint the shadow with the clip's status color
  (approved=green-tinted, flagged=red-tinted).
  - Selected state is a 2px blue border. Add a brand-gradient border + subtle pulsing glow so it reads as "this is the
  one I'm working on."
  - Batch actions panel goes to opacity 0.45 when empty. Better: collapse it entirely with a height transition.
  Half-opacity looks broken, not deliberate.
  - No keyboard shortcut hints. Power users would expect "A = approve, F = flag" indicators on the action buttons.

  UserManagement

  - Invite modal is a plain box. Apply the same frosted-glass + gradient hairline treatment as the auth split card.
  - Filter bar uses raw selects. Convert to chips for role/status filters.
  - User rows are interchangeable. Avatar circles should use the brand gradient (admin) / success gradient (editor) /
  warning gradient (reviewer) — visual role is already encoded in your data, surface it.
  - Last-seen timestamps are gray text. Color the dot next to them: green if active in last 5 min, yellow if last hour,
  gray if older. Now the table tells a story at a glance.
  - No empty state. When there are no users matching a filter, you currently get an empty table.

  EditorView

  - Success state ("Batch Process Complete") is anticlimactic. This is a moment. Add a one-shot confetti sweep or
  gradient sweep across the success banner. Users just waited 5 minutes.
  - Progress bars are plain. Same fix as Upload — gradient + traveling shimmer.
  - File queue items are static. Add stagger on entry, fade on remove.
  - Result cards all look identical. Tint each by detected label color — when scanning the results, color tells you
  "this is presenter, that's b-roll, that's testimonial" without reading.
  - "Open Folder" button is a plain link. Promote to a proper button with the folder icon and a subtle hover lift.

  Cross-cutting components to upgrade once

  These four components touch every page. Fix them once and seven pages improve.

  1. PageHeader.jsx → add eyebrow prop, gradient title prop, optional right-side actions slot. Every page uses it.
  2. EmptyState.jsx → require an icon, title, body, and optional CTA. Replace all the emoji + text patterns.
  3. LoadingState.jsx → support type="grid", type="table", type="cards" with proper shimmer skeletons (CSS @keyframes
  shimmer is already in index.css — wire it up).
  4. A new <SurfaceCard> → standardized panel with optional glow and gradientBorder props. Replace the dozens of inline
  style={{ background: 'var(--surface-panel)', border: '1px solid ...' }} blocks.

  Priority order if you only have a weekend

  If you can spend ~6 hours total, do these in this exact order — biggest visual lift first:

  1. PageHeader gets eyebrow + gradient title. 30 min. Touches 8 pages.
  2. .chip and .filter-bar actually used. 45 min. Filters look modern instantly.
  3. Skeleton loaders in LoadingState. 1 hour. The "did it load?" anxiety vanishes.
  4. Status-colored row borders in tables (JobMonitor + UserManagement). 30 min. Tables stop being walls of gray.
  5. Brand-gradient avatars + hover glow on stat cards. 1 hour. Dashboard stops feeling like a generic admin panel.
  6. Animated dropzone border + progress shimmer. 45 min. Upload becomes the most-noticed page.
  7. EmptyState with proper icon component. 30 min. Every "nothing here" moment improves.
  8. Frosted-glass + gradient border on modals. 30 min. Modals match the auth card.

  Skip the rest until after submission. Items 1–4 alone close 70% of the gap between landing and inner pages.

  What not to do

  - Don't put the 3D diorama on inner pages. It's a marketing flourish; it would feel like a toy on the dashboard. Inner
   pages need calm polish, not spectacle.
  - Don't add Lenis smooth-scroll inside scrollable tables/grids. It's great on landing, terrible on data tables.
  - Don't go heavier on color. Your problem isn't less color, it's more strategic color — accent stripes, status-tinted
  borders, gradient on the 1–2 things per page that matter. Saturating everything makes it worse.
